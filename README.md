# Pakistan Synthetic Weather Dataset 🇵🇰

## About the Project
This project generates a synthetic weather dataset for 10 cities of Pakistan using Python. It contains 365 daily weather records for each city, making a total of 3,650 records for one year.

## Cities Included
- Lahore
- Karachi
- Islamabad
- Peshawar
- Quetta
- Multan
- Faisalabad
- Hyderabad
- Gilgit
- Skardu

## Weather Parameters
The dataset includes:
- Temperature (°C)
- Humidity (%)
- Wind Speed (km/h)
- Rainfall (mm)
- Atmospheric Pressure (hPa)
- Visibility (km)
- UV Index

## Technologies Used
- Python
- Google Colab
- Random Module
- Dictionaries
- Functions and Loops

## Key Features
- Generates 365 daily records for each city.
- Creates 3,650 total weather records.
- Uses city-specific and seasonal weather patterns.
- Displays weather data for a selected city.
- Verifies the generated dataset.

## How to Run
1. Open the `.ipynb` notebook.
2. Open it using Google Colab or Jupyter Notebook.
3. Run the code.
4. Enter a city name, such as `Lahore`.
5. View the generated weather records.

## Important Note
This is a synthetic dataset generated using random values and approximate weather ranges. It does not contain actual historical weather observations.
